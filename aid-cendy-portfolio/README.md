# Aid Cendy Ferrer — Portfolio

Open `index.html` in any modern browser. No build step needed.

```
index.html          page structure
css/style.css       theme tokens, layout, animations
js/main.js          theme toggle, floating nav, filters, reveals, features
assets/images/      optimized photos
```

Fonts (Bricolage Grotesque, Instrument Sans) load from Google Fonts; system fonts are used as a fallback when offline.
Tip: press "T" to switch between light and dark mode.

Sections: Home, About (with photo mosaic), Skills, Contact. All transitions run at 0.3s or less; reveals use IntersectionObserver and only animate opacity/transform.
